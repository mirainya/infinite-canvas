# Infinite Canvas 自由画布重构方案
状态：自由画布内核已实施，产品能力继续完善

## 1. 产品定义
Infinite Canvas 是 AI 图像创作桌面，不是工作流编辑器。
用户在画布上放入图片和文字，直接选择素材、描述意图、生成或修改，再把满意结果整理、下载或保存为模板。生成过程可以追溯，但不以节点和连线占据画布。

核心体验：

- 图片是第一等对象，不再包在“图像输入节点”里。
- 选择的图片就是参考图，不需要先放入图像集合。
- AI 绘图是画布动作，不是长期存在的配置节点。
- 新结果保留在原图附近，不覆盖原图。
- 批量结果用图片组承载，展开后可以自由拆出。
- 关系默认隐藏，只在查看版本时显示。

## 2. 调研吸收
### [basketikun/infinite-canvas](https://github.com/basketikun/infinite-canvas)
吸收图片对象、悬浮工具栏、批量结果叠放、素材引用和单对象生成。舍弃长期显示的配置节点、端口和全画布连线。

### [fal-ai-community/infinite-kanvas](https://github.com/fal-ai-community/infinite-kanvas)
吸收拖放上传、直接变换、流式结果、视野裁剪、缩略图加载和本地交互历史。

### [fancyboi999/Loomic](https://github.com/fancyboi999/Loomic)
吸收“画布 + AI 创作栏”、选择内容进入上下文、异步任务和积分体系。AI 对话不常驻占用右侧空间。

### [Asai2080/asui-canvas](https://github.com/Asai2080/asui-canvas)
吸收图片原位批注、局部修改和新版本就近放置。蒙版与批注属于图片编辑状态，不成为独立节点。

### [Konva](https://github.com/konvajs/konva) / [react-konva](https://github.com/konvajs/react-konva)
采用其 Canvas 场景、选择变换、分层绘制和 React 集成能力作为画布基础。画布对象格式由项目自行维护，不再受白板产品的数据结构和许可证约束。

## 3. 页面结构
登录后直接进入上次画布，不经过项目创建页。

```text
┌ 左侧工具栏 ┬──────────────────────── 自由画布 ────────────────────────┐
│ 画布       │                                                积分 头像 │
│ 添加       │                                                         │
│ 素材       │                 图片、文字、图片组、画板                 │
│ 创作方案   │                                                         │
│ 任务       │          [参考图] [参考图]  描述内容...  [生成]          │
│ 历史       │                      AI 创作栏                           │
└────────────┴────────────────────────────────────────────── 缩放/小地图 ┘
```

- 左侧：固定窄工具栏；点击后展开单层抽屉。
- 中央：完整无限画布，不显示固定标题栏。
- 右上：积分、任务状态、账号入口。
- 对象上方：仅在选中时出现局部工具栏。
- 底部中央：AI 创作栏；无选择时文生图，有选择时参考图创作。
- 右侧：默认留空；复杂设置按需弹出，不常驻。
- 项目名：只在“画布”抽屉中编辑，不悬浮在画布顶部。

## 4. 画布对象
### 图片
图片本身就是对象。默认无标题、无卡片外壳、无端口。选中后显示轻量边框和工具栏：参考、编辑、蒙版、裁剪、切分、放大、下载、更多。

### 文字
直接编辑的自由文本，可作为提示词引用。工具栏提供增强、生成文字、复制和样式。

### 画板
用于整理一组作品或一个套图主题，可命名、设定比例、导出全部内容。画板不是嵌套卡片，只提供边界和标题。

### 图片组
用于承载一次批量生成或一批导入图片：

- 收起时显示主图、数量和轻微叠层。
- 展开时按自适应网格排列，兼顾横图与竖图。
- 可切换主图、删除单张、整组下载、全部拆到画布。
- 单张拖出后成为独立图片，来源关系保留。
- 图片组不承担 AI 绘图的多图输入。

### 批注
箭头、画笔、文字和框选附属于图片版本。它们用于表达修改意图，可隐藏或清除，不作为生成流程节点。

## 5. AI 绘图
“AI 图像”统一改名为“AI 绘图”，但它不再是画布节点。

### 多参考图
- 多选画布图片后，AI 创作栏按选择顺序显示参考图缩略片。
- 支持重新排序、移除和指定主图。
- 可从素材抽屉拖入，也可直接粘贴或上传。
- 直接上传的参考图同步进入素材库，可选择是否放到画布。
- 图片组展开后可多选其中若干张，不要求整组引用。

### 执行
- AI 创作栏的生成按钮只执行当前请求。
- 图片工具栏中的局部修改、放大、切分等按钮只处理当前选择。
- 结果图片提供“再次生成”，自动带回上次模型、描述和参考图。
- 不保留全局“运行画布”；任务抽屉提供批量重试和取消。

### 结果放置
- 单张结果优先放在来源右侧；右侧不足时放到下方。
- 多张结果生成图片组，保持横纵混合的紧凑网格。
- 连续修改沿空闲方向生成版本，不覆盖已有对象。
- 放置只避让附近对象，不重新排列整张画布。

## 6. 版本关系
- 默认不显示连线。
- 选中图片后可打开“版本”视图，只显示当前图片的上一个版本、下一个版本和同批结果。
- 关系线使用短距离曲线，关闭版本视图立即隐藏。
- 任务记录保存模型、提示词、参考图顺序、蒙版、费用和生成时间。
- 删除画布对象不立即删除素材与任务记录。

## 7. 排列规则
取消全画布自动拓扑排列，改为只整理当前选择：

- 智能网格：默认；根据图片比例分配行列。
- 横向排列：适合版本对比和分镜。
- 纵向排列：适合长图和步骤稿。
- 紧凑拼贴：适合灵感板。
- 等宽、等高、等间距和对齐作为局部命令。

智能网格先确定主方向，再按比例分行，禁止只生成单一竖排。

## 8. 图片编辑
- 双击图片进入沉浸式编辑，画布其余内容弱化。
- 支持矩形、套索、画笔蒙版，以及撤销、重做和清除。
- 确认蒙版后回到画布，AI 创作栏自动进入局部修改模式。
- 裁剪为非破坏编辑，保留原图。
- 切分直接生成图片组。
- 下载支持原图、当前裁剪、蒙版和整组 ZIP。

## 9. 模板与套图
模板分为两类，但在左侧统一称为“创作方案”：

- 版式方案：创建画板、占位区和文字布局。
- AI 方案：预设用途、比例、数量、模型和提示结构。

商品套图采用引导抽屉，不生成工作流：

1. 放入商品图、品牌信息和文案。
2. 选择主图、场景、细节、功能或氛围图。
3. 检查每张图的描述和预计积分。
4. 批量生成，结果按类别放入多个画板。
5. 失败项单独重试，完成后整套下载。

个人可把当前选择或画板保存为创作方案；系统方案升级不修改已创建内容。

## 10. 视觉语言
方向为清爽的二次元糖果色工作台，不做幼儿化装饰。

- 背景：`#F8F8FB`，正文：`#302D36`，边线：`#E9E6EE`。
- 草莓粉：`#F06F9E`，薄荷绿：`#49BFA0`，柠檬黄：`#EFC758`。
- 天空蓝：`#58AEDD`，葡萄紫：`#8466C8`，紫色只用于重点动作。
- 对象保持无外壳或 6px 圆角；工具面板最大 8px 圆角。
- 不使用大面积渐变、光球、厚阴影和持续动画。
- 二次元形象只出现在空画布、任务完成和错误状态，不进入高频操作区。
- 图标统一使用 Lucide；常见命令不重复显示长文字。

## 11. 性能方案
- 以 react-konva 的场景渲染替代 React Flow 节点图，画布文档保持独立。
- 图片原文件留在 XFS，画布只加载 256px/512px 缩略图。
- 超过 300 个对象后只绘制视野附近内容，选中对象始终保留。
- 拖动、缩放过程只更新内存；交互结束后再写历史和自动保存。
- 画布对象使用不可变更新，自动保存采用延迟合并；多页面冲突按对象合并。
- 关系线默认不渲染，版本视图只计算局部关系。
- 固定使用 50、200、500、1000 个对象检查打开速度、帧率和内存。

目标：200 个对象接近 60 FPS；500 个对象保持 30 FPS 以上；项目数据返回后 2 秒内可操作。

## 12. 现有系统处理
### 保留
账号中心、登录、积分、项目、自动保存、版本、素材库、XFS、模型配置、异步任务、预扣、退款、任务恢复和管理配置。

### 改造
- `V2Graph` 改为画布文档与独立生成记录。
- `workflow_runs` 的产品概念改为创作任务，后端队列机制继续使用。
- AI 绘图、文本生成、提示词增强和图像切分改为单动作任务。
- 系统模板由节点图改为画布对象与创作参数。

### 删除
十类固定节点目录、端口、连接校验、输出节点、全局运行、拓扑排列和默认连线渲染。

旧节点画布不进入新入口；已保存的 tldraw 自由画布会在首次打开时转换为新文档，并保留原始数据。

## 13. 实施顺序
1. 引入新画布引擎与文档结构，接回账号、项目、保存和素材。
2. 完成图片、文字、画板、选择、拖放、粘贴、下载和局部工具栏。
3. 完成 AI 创作栏、多图引用、真实生图、图片组、版本和任务状态。
4. 接回蒙版、裁剪、切分、放大、XFS、扣费、退款和异常恢复。
5. 完成创作方案、商品套图、性能测试、视觉验收和部署。

## 14. 验收标准
- 登录后直接看到可操作画布。
- 画布上没有固定端口、输出节点或默认连线。
- 图片可点击、拖放、粘贴；左侧对象可拖到指定位置创建。
- 多选图片即可作为 AI 绘图参考图，并能调整顺序和主图。
- 单张与批量生成、局部修改、切分、下载全部可独立执行。
- 批量结果横纵混排自然，版本关系默认隐藏。
- 刷新或关闭页面不影响任务，费用与退款准确。
- 500 个对象达到性能目标，桌面和移动视口无重叠。
