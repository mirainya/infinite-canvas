# Infinite Canvas V2 产品规格
状态：已确认，等待分阶段实施

## 1. 产品定位

Infinite Canvas V2 是面向 AI 图像创作的可视化工作台。用户通过节点组织素材、文本和生成步骤，通过模板复用完整工作流，并在统一的任务与成果系统中管理进度、费用和文件。

V2 是一次重新设计，不迁移旧节点和旧画布。现有生产版本在 V2 完整验收前保持运行。

## 2. 核心原则

- 继续使用 React、React Flow、FastAPI、PostgreSQL、Prism、XFS 和账号中心。
- 云端项目是唯一正式项目来源，不再区分本地项目和云端项目。
- 工作流由服务端执行，关闭或刷新页面不会中断任务。
- 输入、整理和输出节点在浏览器内工作；需要计算的节点由服务端执行。
- 生图、改图和多图融合统一为一个 AI 图像节点。
- 商品套图属于系统模板，不维护独立插件。
- 正式环境采用管理员受控的插件重载。
- 大画布性能属于基础能力，不作为发布后的补充优化。

## 3. 正式节点

### 图像输入

上传、粘贴或替换一张图像。节点输出当前图像，文件上传后进入素材库。节点不需要运行，也不产生费用。

### 文本输入

输入描述、指令或提示词。内容自动保存并立即传递给后续节点。

### 图像集合

汇集多个节点产生的图像，支持排序、选择主图、移除和去重。可以接收单张图像或图像列表。

### 文本集合

管理多条文本或提示词，支持逐条编辑、排序、删除和解析换行文本或 JSON 数组。每条内容可以带简短标题。

### AI 图像

统一完成文生图、参考图创作、多图融合和局部编辑。

- 无参考图：文生图。
- 有参考图：参考图创作或多图融合。
- 有参考图和蒙版：调用 Prism 图像编辑接口，蒙版使用独立字段。
- 有文本集合：逐条执行批量生成。
- 输出主图和完整图像列表。

### 文本生成

调用语言模型完成通用文本生成与改写。支持系统指令、用户内容和可选参考图像，返回 Token 用量供统一计费。

### 提示词增强

将简要描述扩展为专业图像提示词。Meta Prompt 负责产生指令，语言模型负责生成最终结果。只保留统一任务入口。

### 图像切分

按指定行列将一张图像切成独立文件，保留边缘像素和原始顺序，结果进入素材与成果系统。

### 图像输出

作为图像流程终点，支持画廊、灯箱、单张下载、选择下载和批量下载，不再向后连接。

### 文本输出

作为文本流程终点，支持单段和列表查看、复制以及 TXT、JSON 导出，不再向后连接。

## 4. 工作台

- 顶部：项目名称、保存状态、撤销、重做、排列、运行、任务、积分和账号。
- 左侧：项目、节点、模板和素材。
- 中央：无限画布。
- 右侧：当前节点的内容、设置和运行详情。
- 底部：当前项目的任务抽屉。

节点只显示主要内容。模型、比例、数量和高级设置放在右侧属性区。节点标题固定在节点顶部。

## 5. 视觉方向

- 以浅色工作台为主要主题。
- 输入、整理、AI、处理和输出使用不同的低饱和糖果色。
- 节点圆角不超过 8px，阴影保持轻微。
- 不使用大面积单色、装饰光团或持续连线动画。
- 图像使用不裁切主体的缩略图。
- 桌面端提供完整编辑；移动端提供检查、运行、任务和下载。

## 6. 项目、素材与成果

- 项目支持创建、重命名、复制、归档、回收站和命名版本。
- 自动保存只维护当前内容；重要操作前自动创建项目版本。
- 上传素材、AI 成果和处理成果统一进入素材库。
- 节点删除不立即删除素材和成果。
- 每次节点运行创建新的成果版本，不覆盖旧结果。
- 成果记录来源节点、任务、模型、提示词、费用、尺寸和格式。
- 画布只保存文件地址，不保存 Base64 图像。

## 7. 模板

模板包含节点、连接、默认设置、必填内容、检查位置、封面、分类、费用范围和版本。

- 使用模板会创建独立项目副本。
- 系统模板升级不会修改已有项目。
- 用户可以把选中节点或整张画布保存为个人模板。
- 系统模板由管理员审核和发布。
- 首批系统模板：文本生图、参考图创作、局部修改、多图融合、商品套图、九宫格切分、批量提示词生图。

## 8. 商品套图

商品套图由标准节点组成，分为四个阶段：

1. 素材准备：商品图、商品描述、数量和比例。
2. 视觉方案：分析商品并规划主图、场景图、细节图、功能图和氛围图。
3. 提示词检查：逐条修改、排序、增加、删除和确认提示词。
4. 批量生成：按条目生成图片，失败项单独重试。

每张结果始终关联对应方案和提示词，可以单独修改并重新生成。

## 9. 任务与费用

- 服务端负责工作流顺序、暂停、继续、取消和恢复。
- 批量任务拆分为独立条目，单次最多生成 30 张图像。
- 运行前显示预计任务数量和积分。
- 开始时预扣，完成后按实际成功数量结算。
- 未执行、取消和失败部分自动退款。
- 工作流、节点任务和钱包交易共享请求编号，防止重复扣费。
- 页面刷新、网络恢复和服务重启后重新查询真实任务状态。

## 10. 扩展与热加载

- 核心节点随应用发布。
- 内置处理插件随应用发布，并可由管理员停用。
- 扩展插件由管理员上传受信任的插件包。
- 开发环境支持自动热加载。
- 正式环境在检查、试运行成功后由管理员启用新版本。
- 正在运行的任务继续使用启动时的插件版本。
- 扩展插件使用标准节点界面；需要专用界面的能力随应用版本发布。

## 11. 大画布性能

- 200 个节点、400 条连线时接近 60 FPS。
- 500 个节点、1000 条连线时保持 30 FPS 以上。
- 300 个节点的项目在数据返回后 2 秒内可操作。
- 单个节点变化只更新相关节点。
- 画布节点只加载 256px 或 512px 缩略图。
- 只完整显示当前视野内的节点。
- 缩放较小时自动简化节点内容。
- 节点超过 150 个后自动启用大画布模式。
- 撤销和重做记录具体变化，不复制完整项目。
- 自动保存只提交发生变化的内容。
- 搜索、排列和大型序列化在后台线程执行。

发布前使用 50、200、500 和 1000 节点的固定项目检查打开速度、帧率、内存、保存和状态更新。

## 12. 安全与隔离

- 项目、版本、素材、任务和个人模板每次访问都检查所有者。
- 管理员身份只来自账号中心。
- 外部图像通过安全下载服务读取，禁止访问本机、内网和云服务元数据地址。
- Prism、XFS、Meta Prompt 和账号中心密钥只保存在服务端。
- 插件不能取得原始密钥，也不能自行扣费。
- 日志不记录密钥、完整原图或不必要的完整提示词。

## 13. 实施阶段

1. V2 分支、测试环境、新迁移和基础服务。
2. 项目工作台、自动保存、版本和回收站。
3. 高性能画布、局部历史、缩放简化和折叠分组。
4. 六个浏览器节点、素材库、成果和下载。
5. 服务端工作流、任务队列、计费、退款和恢复。
6. AI 图像、文本生成、提示词增强和图像切分。
7. 模板系统、首批模板和商品套图。
8. 扩展管理、受控热加载和管理后台。
9. 自动测试、性能、安全、部署和正式发布验收。

每个阶段独立完成测试。当前生产版本保持不变，直到 V2 完整达到发布标准。

## 14. 首版不包含

- 多人实时协作。
- 公开项目分享。
- 公共插件市场。
- 任意脚本节点。
- 视频与音频节点。
- 定时工作流。
- 移动端复杂画布搭建。

这些能力不阻塞 V2 首次正式发布。

## 15. 发布标准
- 十个正式节点功能完整。
- 商品套图可以分阶段完成并下载成果。
- 模板能够创建、发布、复制、升级和使用。
- 页面刷新和服务重启后任务状态正确。
- 批量任务不会重复生成、重复扣费或重复退款。
- 项目、素材、模板和任务严格按账号隔离。
- 大画布达到既定性能指标。
- API、任务服务和插件服务支持开机启动与异常重启。
- 自动测试、视觉检查、性能检查和安全检查全部通过。
